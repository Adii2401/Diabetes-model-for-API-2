🩺 Diabetes Prediction Model with API

📌 Project Overview

This project is a Machine Learning-based Diabetes Prediction System that predicts whether a person is likely to have diabetes based on certain medical and health-related features.

The model is trained using the PIMA Indians Diabetes Dataset and uses a Support Vector Machine (SVM) algorithm for classification.

The trained Machine Learning model is integrated with an API to make predictions by accepting input data and returning prediction results.
